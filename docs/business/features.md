# Opis funkcji

## Czym jest FamilyOrganiser?

Prywatna aplikacja webowa do zarządzania domowym budżetem i organizacją życia rodzinnego.
Jeden członek rodziny dodaje — wszyscy widzą. Prosto, bez zbędnej filozofii.

## Dla kogo?

Dla 2–6 osobowej rodziny, która chce mieć wspólny podgląd na:
- Co trzeba kupić
- Co trzeba zrobić w domu
- Kto ile wydał
- Ile zostało do końca miesiąca
- Jak rosną oszczędności i inwestycje

## Funkcje

### 🛒 Lista zakupów
- Wspólna checklista dla całej rodziny
- Dodajesz pozycję → każdy widzi
- Odhaczasz kupione → znika z aktywnej listy
- Widać kto dodał i kto kupił

**Flow:** Wejdź w "Lista zakupów" → "Nowa lista" → dodawaj pozycje → odhaczaj kupione

### ✅ Zadania domowe
- Lista rzeczy do zrobienia w domu
- Możesz przypisać do konkretnej osoby
- Opcjonalny termin wykonania
- Odhaczasz zrobione → widać kto i kiedy

**Flow:** Wejdź w "Zadania" → "Nowa lista" → dodaj zadanie → przypisz osobę → odhacz

### 🧾 Wydatki
- Prosty dziennik wydatków: kwota + na co + kiedy
- Każdy członek rodziny widzi wszystkie wydatki
- Suma miesięczna na górze
- Żadnych kategorii — po prostu wpisujesz

**Flow:** Wejdź w "Wydatki" → "Dodaj" → kwota + opis → zapisz

### 🥧 Budżet miesięczny
- Wpływy (pensja, dodatkowe) + wydatki
- Wydatki mogą być stałe (czynsz, internet — same się kopiują co miesiąc)
- Live balance: na górze widzisz ile zostało
- Pasek wizualny: zielony = plus, czerwony = minus
- Szybki kalkulator oszczędności: wpisz "chcę odłożyć 500 zł" → widzisz dzienny budżet

**Flow:** Wejdź w "Budżet miesięczny" → dodaj dochody → dodaj wydatki → obserwuj pasek

### 📈 Inwestycje
- Wpisz lokatę/obligacje/akcje: kwota, oprocentowanie, okres
- Auto-obliczanie: data końca, prognozowany zysk, kapitał końcowy
- Podsumowanie wszystkich inwestycji na górze

**Flow:** Wejdź w "Inwestycje" → "Dodaj" → wpisz parametry → zobacz prognozę

## Słownik pojęć

| Pojęcie | Znaczenie |
|---------|-----------|
| Grupa rodzinna | Zbiór osób (max 20) które widzą swoje dane |
| Admin rodziny | Osoba która założyła grupę, może zapraszać i usuwać |
| Wydatek stały | Wydatek który powtarza się co miesiąc (czynsz, internet) |
| Live balance | Kwota "zostaje" aktualizowana na żywo po każdym wpisie |
